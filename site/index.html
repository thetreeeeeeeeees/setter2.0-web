About

What is setter2.0?

setter2.0 is a DDIM model trained/tested on a dataset of about 80,000 public Kilter board climbs, all with 2 or more ascents, right now for 700 epochs. The model spatially encodes climbs in a grid format, with each cell containing 5 channels (empty, start, hand, foot, finish). Then, using reverse-step diffusion (with a convolutional U-net to predict noise to subtract) the model starts with Gaussian noise and slowly transforms it into a viable climb. Finally, the model moves from a continuous space to discrete holds by taking the max channel for every hole in the fully denoised sample.

What about 1.0?

setter1.0 was a friend and I's first attempt at the problem of generating Kilter board climbs, and used seq2seq transformer architecture similar to in NLP (represent each hold as a word, and then build a sentence. The finished product is your climb!) Unfortunately, this approach had a few weaknesses: first, climbs do not have an inherent sequence in the same way that sentences do, and so choosing an arbitrary ordering of holds created undesirable biases in the model. Second, transformers are built to find the "correct" next token, meaning a set grade and angle parameter pair would always generate the same climb. Introducing temperature (randomness) solved this issue, but vastly decreased the quality of generated climbs.

Why Diffusion?

I initially started setter2.0 for the express purpose of learning to write a DDPM in the first place; I frankly didn't expect any success other than my own learning, and chose Kilter board climb generation as my problem because I was already fairly familiar with it. That said, I quickly realized that diffusion has a lot of useful properties for this type of problem. Perhaps most obviously, diffusion can work in a 2 dimensional space (as it does for image generation), allowing for the model to understand the spatial positioning of climbs in the same way that humans do. Additionally, as diffusion fundamentally works to transform random Gaussian noise into the target space, the setter1.0 issue of needing to add quality-destroying temperature doesn't exist: there is no temperature needed because it is all temperature.

Reading the visualizer

Predicted climb shows what the model currently predicts to be the denoised climb. In early time-steps, this is often an empty board, as the model has not yet ramped up the hold role values in any cells. Confidence shades each hole by how strongly the model leans toward a hold there. Again, in early time-steps, this is often empty. Relative confidence compares each hole with the most likely hold on the entire board, showing where the model starts leaning early on. Noisy sample shows the actual noise the model is transforming into the final climb.

Limitations

None of the generated climbs have been tested on a real Kilter board, so grades may be inaccurate. Additionally, by nature of diffusion, some seeds will begin with noise and further add noise that, in conjunction, will cause structural errors to occur (e.g. 3 start/finish holds; as cells decide their roles in parallel, sometimes multiple can simultaneously gain a role before the model "realizes"). If this happens, sorry, and please try a different seed!
